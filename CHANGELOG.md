# Changelog

All notable changes to this project are documented here.

## 0.1.0 - 2026-11-23

### Added

- Playwright CLI `0.1.25` installation under Node 22.
- OpenCode and Claude Code restricted worker agents.
- Global `/playwright` commands and Playwright skills for both clients.
- Lean stdio MCP server with six orchestration tools.
- Atomic per-profile lock daemon and live registry.
- Persistent and ephemeral session runner.
- Snapshot, ref extraction, ref fill, and bounded artifact storage.
- Authentication pause and interactive handoff on `DISPLAY=:0` and `DISPLAY=:99`.
- Zenpai posting and Instagram hygiene compatibility hooks.
- Tests for parallel workers, profile collision, dashboard state, MCP handshake, configuration handshake, and artifact pruning.
